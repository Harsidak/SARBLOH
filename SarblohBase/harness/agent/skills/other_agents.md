Something on the board may move without you. Establish which kind it is: a thing that merely blocks, a thing that comes towards you, a thing that runs away, or a thing that only watches and changes what is allowed when it sees you. Learn its rule by standing still for one turn, then moving one step and watching its reply. If it follows you, the distance between you is a quantity you can plan with. If it watches, find the cells it cannot see. Many of these move only when you do, which makes waiting a real move with a real cost.
