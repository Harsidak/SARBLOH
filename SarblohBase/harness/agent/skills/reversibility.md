Ask early whether a move can be taken back, because the answer sets how freely you may experiment. If doing the same thing twice returns the board to where it was, probe as much as you like. If something falls, is consumed, gets pushed into a corner, or opens once only, the board is permanently different and you must be sure before committing. Keep a note of which moves are safe to repeat and which are not. Things you pick up usually persist for the rest of the level and sometimes beyond it, so check what you are carrying before concluding that a door will not open.
