Nothing tells you what winning means, so decide which kind of goal this is. Reaching a cell is the common case, but a level may instead want you to hold a condition for several turns, collect up to a number the display is counting, arrange several things into a configuration, satisfy every pair before any of them count, or avoid something entirely. The display is the strongest clue: a number that only rises is a target to reach, one that only falls is a budget. Write your belief down as a sentence and check it against whatever happened the last time you won.
