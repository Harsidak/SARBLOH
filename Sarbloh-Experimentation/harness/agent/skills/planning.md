How to play a level. 1) Look (free): name what you might control, the walls, the targets and any counter on the edge; the briefing's GUESSES are a start. 2) Learn the dynamics: on the first one or two levels, spend the moves you need to see what the controls do to the objects and what wins; after that, test in code, not on the board. 3) Model it: write `step(state, move)` in `ipython` from what you saw. 4) Search and act: search the model (BFS) for the shortest path to your goal and send it with `act()` in the same call. Have the code check the board after each `act()` and stop when it differs from the model; then fix the model and search again. 5) Later levels: start from your code, skills and lessons, and test only what is new. Every level can be solved: if search finds no path, test the rule you trust least. When two goals compete, spend one move that tells them apart.
