PART E — bench.py --sweep, BUDGET-AWARE
  One invocation scores every registered component against a shared control arm.
  - --budget-hours N: estimate per-cell cost from the stored baseline, pick
    games/seeds to fit, and PRINT UP FRONT the smallest effect the selection
    can resolve.
  - Per component: dHonest, dOfficial, think-time share, verdict
    HELPS / HURTS / NO EVIDENCE / NO-OP via paired_verdict() (bench.py:435) —
    a score-neutral-but-different-route arm is never filed as inert.
  - Below the noise floor -> NO EVIDENCE + the seed count that would resolve
    it. scores/noisefloor.json stores the untouched baseline's seed spread
    (lp85 alone spans 0.068-0.497 honest across seeds 0-9): floor is measured,
    never guessed.
  - Run ONCE at --budget-hours 2 to rank where to look; it answers "where
    next", not "did we improve" — do not ritualise re-runs.
