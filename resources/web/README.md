# resources/web/

Scraped pages as markdown, one file per source, each with a `.meta.yaml`.

Naming: `YYYY-MM-DD_domain_slug.md` — e.g. `2026-09-21_arcprize_leaderboard.md`.

Keep the date in the filename. Leaderboards, competition pages and harness write-ups change during the
competition, and a claim cited from an undated scrape cannot be defended.

Capture the substance, not the chrome: strip navigation and ads, keep tables, figures captions and numbers
verbatim. If a number matters, quote it exactly and note where on the page it appeared.
