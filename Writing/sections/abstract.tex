\begin{abstract}
ARC-AGI-3 scores an agent by how few actions it needs, relative to a human, to master interactive games it has never seen, under strictly offline, single-GPU, nine-hour limits. We argue that the primary bottleneck is not policy deduction but spatial grounding: shown raw $64{\times}64$ integer grids, frontier models burn hundreds of actions rediscovering mechanics a human grasps at a glance. We present \textsc{Sarbloh}, an agent built around a deterministic host-side perception engine and a code-as-action runtime. In $\approx$35\,ms per frame, the engine produces three aligned views: an object-centric state with identity tracking across steps, a briefing that separates verifiable geometric invariants from affordance hypotheses paired with one-action tests, and an annotated spatial map. The agent writes Python world models and action plans over these views, supported by an append-only context that reuses 98.4\% of the prefix cache and a priority scheduler that shares one GPU across 25 concurrent games. In a controlled rubric, structured perception raises affordance identification from 3/28 to 25/28 while cutting input tokens by 89.4\%. On one RTX PRO 6000, \textsc{Sarbloh} clears 143 of 183 public levels in 8.2 hours and scores 16.53 on the hidden Kaggle evaluation, 13.7$\times$ the Milestone~\#1 baseline. All code is released under Apache-2.0.
\end{abstract}
