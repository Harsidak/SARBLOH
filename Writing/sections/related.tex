\section{Related Work}
\label{sec:related}

\paragraph{Perceptual representations in interactive ARC agents.}
Prior ARC-AGI-3 architectures differ across planning strategies, context memory management, and external tooling, yet they share a uniform perceptual assumption: the visual grid is transmitted directly to the reasoning model as raw unparsed data, delegating spatial scene decomposition entirely to neural inference (Table~\ref{tab:field}). 
Specifically, the first Milestone winner (the Duck harness \citep{duck2026,arcprizemilestone1}) serializes the board as composite ASCII character matrices alongside rendered image frames. The second- and third-place Kaggle systems pass annotated screenshots to Gemma-4-31B, prompting the vision model to emit JSON action sequences directly \citep{arcprizemilestone1}. In the frontier API regime, VISTA \citep{vista2026} deploys a multimodal harness with lossless visual frame retention, while Arcgentica \citep{knutsen2026arcgentica} and Prime Agent \citep{karten2026prime} expose the environment within a persistent Python REPL, leaving the language model to write its own parsing scripts over raw coordinate arrays.

\paragraph{Core knowledge grounding and geometric invariants.}
Across all existing systems, the agent observes the world as an integer matrix, an ASCII string, or an unannotated visual raster. Consequently, fundamental spatial primitives, including 4-connected entity segmentation, topological containment, lattice-constrained reachability, and affine symmetries, are left to be reconstructed by the neural backbone from raw tokens. As our motivating ablations establish (Section~\ref{sec:motivation}), this unparsed representation forms the primary source of action inefficiency and hallucination. In contrast, \textsc{Sarbloh} computes geometric invariants deterministically on the host in $\mathcal{O}(HW)$ time, maintains persistent bipartite entity tracking across temporal steps, and explicitly decouples mathematical certainties from single-action testable affordance hypotheses.

\paragraph{Autonomous code generation and programmatic execution.}
The CodeAct paradigm \citep{wang2024codeact} demonstrated that expressing agent actions through executable programming primitives outperforms specialized JSON action schemas. Prime Agent \citep{karten2026prime} adapted this to ARC-AGI-3 by allowing models to execute Python code within an interactive environment. However, earlier harnesses decoupled model reasoning into disjoint tools for code simulation and action execution, forcing expensive context-switching roundtrips. \textsc{Sarbloh} unifies these operations within an asynchronous execution contract (\code{await play()}), allowing models to hypothesize, simulate, and commit multi-step actuation trajectories within a single reasoning turn.
