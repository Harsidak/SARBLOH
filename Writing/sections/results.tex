\section{Results and Empirical Evaluation}
\label{sec:results}

We evaluate \textsc{Sarbloh} across three rigorous empirical dimensions: (i) official evaluation trajectory on the undisclosed Kaggle ARC-AGI-3 benchmark, (ii) controlled hardware-matched comparative benchmarking against the Milestone~\#1 winning Duck harness on identical enterprise hardware, and (iii) systems execution telemetry quantifying computational and token efficiency under our single-GPU budget.

\subsection{Evaluation Trajectory on Hidden Benchmark}
\label{sec:trajectory}

The official Kaggle ARC Prize track evaluates submitted notebooks on held-out, undisclosed game environments within an offline execution sandbox, providing an uncontaminated measure of out-of-distribution reasoning and generalization. 

Our initial architectural baseline---a direct port of the Prime Agent framework \citep{karten2026prime} operating with open-weight models (Gemma-4-31B and Qwen3.8-27B)---achieved scores between 0.00 and 0.27. Detailed trace diagnostics revealed that while the model successfully generated Python syntax, it engaged in unguided brute-force search: across a 10-game evaluation, the agent initiated over 350 voluntary resets without successfully identifying a single goal state.

Systematic architectural interventions drove continuous, measurable performance gains across successive builds:
\begin{enumerate}
    \item \textbf{Serving and Backbone Upgrade}: Migrating the inference engine to Qwen3.8-Flash-Next on SGLang, optimizing prompt prefix-caching, and enabling concurrent multi-game execution elevated the official score to \textbf{5.14}.
    \item \textbf{Tool Unification and Context Invariants}: Merging action dispatch directly into the Python kernel (\code{await play()}) and replacing lossy summarization with deterministic context draining increased performance to \textbf{5.65} and \textbf{6.06}.
    \item \textbf{Symbolic Memory and Priority Scheduling}: Introducing cross-level memory dictionaries, real-time AST code graph tracking, and utility-driven priority scheduling across concurrent sessions yielded a substantial leap to \textbf{10.98}.
    \item \textbf{Integrated Multimodal Perception Core}: Integrating the complete multimodal perception engine (combining bipartite tracking, geometric invariants, and affordance hypothesis testing) alongside refined context guardrails established our peak verified score of \textbf{16.53}.
\end{enumerate}
This trajectory represents a 13.7$\times$ efficiency improvement over the 1.21 score that achieved first place in Milestone~\#1 (June 2026), achieved over a 24-day engineering cycle. While top-tier submissions on the live public leaderboard have achieved higher aggregate scores through proprietary ensemble scaling and extensive pre-training corpora, \textsc{Sarbloh} demonstrates that disciplined perceptual grounding, monotonic KV-cache management, and speculative execution deliver unprecedented reasoning density within the strict resource envelope of a single enterprise GPU.

\subsection{Hardware-Matched Comparative Benchmark against Milestone \#1 Baseline}
\label{sec:matched}

To rigorously isolate the algorithmic and systems contributions of our agent from underlying hardware capabilities, we conducted an extensive controlled benchmark against a recent release of the Tufa Labs Duck harness \citep{duck2026}---the architecture that won Milestone~\#1. Both agents were deployed on an identical server platform featuring a single NVIDIA RTX PRO 6000 (96\,GB VRAM) and identical SGLang runtime configurations serving the Qwen3.8-Flash-Next model. The Duck harness executed four concurrent passes per game (totaling 100 concurrent execution streams), whereas \textsc{Sarbloh} executed a single pass across the 25 public games governed by our dynamic priority scheduler.

Figure~\ref{fig:curves} plots the cumulative count of cleared levels as a function of wall-clock execution time. \textsc{Sarbloh} demonstrates a pronounced advantage in discovery speed throughout the entire nine-hour window:
\begin{itemize}
    \item At $t=1.0$\,hour, \textsc{Sarbloh} clears 73 levels compared to 54 for the baseline (35.2\% advantage).
    \item At $t=2.0$\,hours, \textsc{Sarbloh} clears 97 levels compared to 63 for the baseline (54.0\% advantage).
    \item At $t=4.0$\,hours, \textsc{Sarbloh} clears 136 levels compared to 103 for the baseline (32.0\% advantage).
    \item At the conclusion of the execution envelope ($t=8.2$\,hours), \textsc{Sarbloh} resolves \textbf{143} of the 183 total levels (78.1\% completion), whereas the Duck harness completes 129 distinct levels across its four concurrent passes.
\end{itemize}

In time-bounded evaluations, prioritizing productive exploratory paths accelerates the discovery of distinct level solutions.

\subsection{Action Efficiency on Cleared Levels}
\label{sec:efficiency}

Because RHAE penalizes superfluous exploration quadratically, raw level completion counts do not fully convey operational efficiency. We therefore quantify the action ratio $a_l / h_l$ across all successfully cleared levels.

Across our primary offline evaluation run, the \emph{median} action ratio achieved by \textsc{Sarbloh} on cleared levels was \textbf{0.77} relative to the human baseline. In accordance with Equation~\eqref{eq:rhae}, this level of efficiency earns the maximum allowable reward cap ($S_l = 1.15$). This metric demonstrates that once \textsc{Sarbloh} correctly induces the underlying mechanics of a level, its execution-grounded planning engine operates with super-human efficiency: the agent synthesizes optimal trajectory plans in code and commits them directly via speculative path execution.

Decomposing the error budget relative to a theoretical maximum score across the 25 public environments reveals that of the 40.6 points lost from a perfect score:
\begin{itemize}
    \item 12.6 points (31.0\%) result from minor action overhead on completed levels where $a_l > 0.93\,h_l$.
    \item 8.0 points (19.7\%) result from 13 levels that were actively attempted but failed to terminate within the action budget.
    \item 19.5 points (48.0\%) result from subsequent compositional levels that were never reached because the agent stalled on an antecedent stage.
\end{itemize}
This error decomposition confirms that the overwhelming majority of score loss is attributable to perceptual incomprehension on antecedent levels rather than planning inefficiency once a level is understood.

\subsection{Failure Mode Analysis and Ablations}
\label{sec:failures}

Detailed trace audits across unresolved levels revealed two primary operational failure modes:
\begin{enumerate}
    \item \textbf{Cyclic Action Stalls}: In early builds lacking the state revisit leash, four games approached within 2--15 actions of their 2,000-action ceiling and entered degenerate continuation loops, emitting repetitive ``\code{Holding...}'' tokens across approximately 14,000 idle turns and consuming 1.24\,B cached prompt tokens without altering the environment state. Enforcing a hard ceiling of 400 turns per game alongside the state revisit leash effectively eliminated these degenerate loops.
    \item \textbf{History Code Stubbing Negative Transfer}: In an exploratory ablation aimed at token conservation, historical code cells in the prompt context were replaced with single-line stub markers (e.g., ``\code{\# [code executed]} ''). Rather than writing novel solution code, the small 6B-active model mirrored the stub in 97.7\% of subsequent turns, completely collapsing planning capacity (0 levels cleared). Small open-weight models exhibit intense in-context imitation bias, necessitating the retention of full syntactic code traces.
\end{enumerate}
