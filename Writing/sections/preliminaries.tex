The ARC-AGI-3 benchmark \citep{arcagi3} defines an uninstructed, discrete-time sequential decision process structured as an ordered progression of compositional levels $\{1, \dots, n\}$. At each interaction step $t$, the agent receives a discrete visual grid observation $g_t \in \{0, \dots, 15\}^{H \times W}$ with spatial dimensions bounded by $H, W \le 64$, where each coordinate denotes one of 16 categorical color indices. In addition to the visual grid, the environment exposes the episode termination status $s_t \in \{\code{NOT\_FINISHED}, \code{WIN}, \code{GAME\_OVER}\}$ alongside the count of levels resolved so far. 

To interact with the environment, the agent selects an action from the action set $\mathcal{A}$, defined in Equation~\eqref{eq:actions}:
\begin{equation}
\label{eq:actions}
\begin{aligned}
\mathcal{A} = \{ & \code{ACTION1}, \dots, \code{ACTION5}, \\
                 & \code{ACTION6}(x,y), \code{ACTION7}, \code{RESET} \}.
\end{aligned}
\end{equation}
In Equation~\eqref{eq:actions}, actions \code{ACTION1}--\code{ACTION4} represent cardinal directional displacements, actions \code{ACTION5} and \code{ACTION7} denote game-specific discrete triggers, and \code{ACTION6}$(x,y)$ specifies an arbitrary continuous spatial coordinate click parameterized by $x \in [0, W-1]$ and $y \in [0, H-1]$. Environments provide zero upfront task directives, as action semantics, controllable entity embodiment, and terminal win conditions are latent. The agent must infer these operational rules entirely from transition dynamics, where earlier levels isolate elemental mechanics and subsequent levels compose them hierarchically \citep{spelke2007core}.

Benchmark performance is evaluated using \emph{Relative Human Action Efficiency} (RHAE). For each level $l$, let $h_l$ denote the upper-median human action baseline, and let $a_l$ represent the cumulative count of physical actions committed by the candidate agent. The per-level efficiency score $S_l$ is defined in Equation~\eqref{eq:level_score}:
\begin{equation}
\label{eq:level_score}
S_l = \min\!\left(1.15,\, \left(\frac{h_l}{a_l}\right)^2\right).
\end{equation}
Across an entire game comprising $n$ levels where the agent successfully completes $k \le n$ levels, the cumulative game efficiency score $E$ is defined in Equation~\eqref{eq:rhae}:
\begin{equation}
\label{eq:rhae}
E = \frac{1}{\sum_{l=1}^n l} \min\!\left(\sum_{l=1}^k l,\; \sum_{l=1}^n l\, S_l\right).
\end{equation}

Equation~\eqref{eq:level_score} and Equation~\eqref{eq:rhae} establish three governing operational properties that dictate our agent architecture:
\begin{enumerate}
    \item \emph{Quadratic Exploration Penalty}---Because action counts enter Equation~\eqref{eq:level_score} inversely squared, unguided exploratory actions penalize the final score quadratically. An agent requiring twice the human baseline actions retains only 25\% of the available credit.
    \item \emph{Zero-Cost Internal Computation}---Reasoning latencies and host-side execution are strictly non-penalized, and only physical actions committed to the environment register in $a_l$. This structure strongly favors extensive host-side geometric parsing and speculative algorithmic planning over trial-and-error exploration.
    \item \emph{Progressive Reward Scaling}---The linear level multiplier $l$ in Equation~\eqref{eq:rhae} weights later compositional levels substantially higher, rewarding agents that generalize foundational mechanics induced during earlier stages.
\end{enumerate}

\paragraph{Offline Evaluation and Resource Bounds.}
The official Kaggle evaluation track evaluates candidate agents on held-out, undisclosed environments within an isolated execution sandbox without external network access. Computation is strictly bounded to a single NVIDIA RTX PRO 6000 GPU (Blackwell architecture, 96\,GB VRAM) and 176\,GB of host RAM, subject to an inviolable nine-hour wall-clock execution ceiling for the entire evaluation suite. Furthermore, all model weights and dependencies must be open-source and pre-packaged within the submission container, contrasting sharply against unconstrained frontier API baselines (Table~\ref{tab:field}). Under these constraints, the operational budget is governed by generation decode throughput and the length of context history that can be retained in the GPU's warm prefix cache without triggering expensive quadratic recomputations.
