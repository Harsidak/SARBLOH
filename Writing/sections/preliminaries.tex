\section{Preliminaries and Related Work}
\label{sec:prelim}

\subsection{Environment}
\label{sec:env}
An ARC-AGI-3 environment \citep{arcagi3} is an uninstructed, discrete-time game made of an ordered sequence of levels $\{1, \dots, n\}$. At each step $t$ the agent sees a frame $g_t \in \{0, \dots, 15\}^{H \times W}$ with $H, W \le 64$, the episode state $s_t \in \{\code{NOT\_FINISHED}, \code{WIN}, \code{GAME\_OVER}\}$ and the number of levels cleared. It then picks an action from
\begin{equation}
\begin{split}\mathcal{A} = \{&\code{ACTION1}, \dots, \code{ACTION5},\\ &\code{ACTION6}(x,y), \code{ACTION7}, \code{RESET}\},\end{split}
\end{equation}
where \code{ACTION1}--\code{ACTION4} are directional, \code{ACTION5} and \code{ACTION7} are game-specific, and \code{ACTION6}$(x,y)$ is a click at pixel $(x,y)$. Nothing is explained up front: what the actions do, which object the agent controls and what wins the level must all be inferred from transitions. Early levels introduce single mechanics and later levels compose them \citep{spelke2007core}.

Games are scored by \emph{Relative Human Action Efficiency} (RHAE). Let $h_l$ be the human baseline for level $l$ (the upper-median human action count) and $a_l$ the agent's action count. Then
\begin{equation}
\begin{split}
S_l &= \min\!\left(1.15,\, \left(\frac{h_l}{a_l}\right)^2\right),\\
E &= \frac{\min\!\left(\sum_{l=1}^k l,\; \sum_{l=1}^n l\, S_l\right)}{\sum_{l=1}^n l},
\end{split}
\label{eq:rhae}
\end{equation}
where $k \le n$ is the number of levels cleared, and the benchmark score is the mean of $E$ over games. Three consequences drive our design. Extra actions are penalized quadratically, so an agent that needs twice the human count keeps only 25\% of the credit. Thinking and host-side computation are free, and only actions sent to the environment count in $a_l$, which favours planning in code over trial and error. And the weight $l$ pushes the score toward later levels.

\paragraph{Offline evaluation and resource bounds.}
The official Kaggle track runs a submitted notebook on held-out games with no network access. It gets one NVIDIA RTX PRO 6000 (Blackwell, 96\,GB VRAM), 176\,GB of host RAM and a nine-hour wall-clock limit for the whole suite, and all weights must be open and packaged with the notebook. The budget is therefore decode throughput, since reasoning is bounded by tokens per second, and the length of prompt that can stay in the warm prefix cache without eviction or recomputation.

\subsection{Related Work}
\label{sec:related}

\paragraph{Static ARC.}
Static ARC \citep{chollet2019measure} was first attacked with search over hand-built DSLs \citep{wind2020icecuber}, then with graph, library and MDL-based synthesis \citep{xu2023arga,ellis2021dreamcoder,ferre2025madil}, and in 2024 with test-time training and neural program induction \citep{akyurek2024ttt,arcprize2024,li2024induction,jolicoeur2025trm}. These methods map a few demonstration grids to one output grid and have no action loop.

\paragraph{Interactive Agents and World Models.}
General LLM agents interleave reasoning and tool calls \citep{yao2022react} or grow libraries of code skills \citep{wang2023voyager}. On ARC-AGI-3, \emph{Prime Agent} \citep{karten2026prime} gives a frontier model a persistent IPython REPL, and our first harness was an open-weight port of it. \emph{Executable World Models} \citep{rodionov2026ewm}, \emph{Tycho} \citep{lehmann2026tycho} and related work \citep{tang2024worldcoder,lehrach2025cwm} synthesize Python simulators of the game and search inside them, and \citet{rudakov2025graph} rank actions by visual salience. All of these use unbounded proprietary APIs and report only on the public games, so none runs in the offline, one-GPU setting.

\paragraph{How Prior Agents Perceive the Game.}
Across these systems the perception layer is thin: the frame reaches the model as raw data, and the model recovers structure itself. The Duck harness passes composite ASCII grids together with visual renderings of the board \citep{duck2026}. The second- and third-place Kaggle systems feed annotated frames to Gemma-4-31B, which emits JSON action sequences directly \citep{arcprizemilestone1}. \emph{VISTA} \citep{vista2026} adds a multimodal visual harness that keeps every frame losslessly. Arcgentica \citep{knutsen2026arcgentica} and Prime Agent expose the game through a REPL, so the model must write its own code to parse the grid. In every case objects, connectivity, containment and symmetry are left to the model to infer from pixels or characters, which is the step our motivating study (Section~\ref{sec:motivation}) finds most costly. We know of no prior ARC-AGI-3 agent that computes these facts exactly on the host, tracks object identity across frames, or attaches a one-action test to each uncertain hypothesis.

\paragraph{Symbolica's Arcgentica.}
\emph{Arcgentica} \citep{knutsen2026arcgentica} is the closest frontier-API relative of our harness. Built on the open-source Agentica SDK, each agent has a persistent Python REPL and can spawn sub-agents that receive only the context their task needs. Symbolica reported 36.08\% on the 25 public games with Claude Opus 4.6 (high effort), passing 113 of 182 playable levels at a stated cost of \$1{,}005 \citep{symbolica2026arc3}. The score was not certified by the organizers. Like \textsc{Sarbloh Agent} it reasons in a persistent code environment and keeps context small, but it delegates to sub-agents whereas we keep one append-only context and drain it deterministically (Section~\ref{sec:method}).

\paragraph{The Open-Weight Offline Frontier.}
The direct baseline class consists of open-weight systems run under the official Kaggle offline protocol (Table~\ref{tab:field}). The Milestone~\#1 winner (June 2026) is Tufa Labs' \emph{Duck} harness \citep{duck2026,arcprizemilestone1}, which runs Qwen~3.6 27B in an interactive Python environment and evicts old context to keep running. Its authors found that rigid hand-built toolkits hurt compared with unconstrained code execution. As Table~\ref{tab:field} shows, \textsc{Sarbloh} sets a new state of the art in this offline open-weight class.
