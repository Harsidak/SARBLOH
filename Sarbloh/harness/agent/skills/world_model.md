A world model is your best guess of the game's rule, written as Python: `step(state, move)` returns the next state. The game is deterministic, so a correct model predicts every step exactly. Build it from the change lines: which object moved, how far, what blocked it, what appeared or vanished, what the HUD did. Write each rule concretely ("A1 moves obj 4 up 5 until a G wall"), and let the model grow as long as the game needs. You do not need proof to act on it: act on your best model and compare. When a prediction is wrong, the model is wrong there: fix it, mark the old rule refuted and say what really happened.
Example: `4 R 3x3 r10-12 c20-22` and `9 N 3x3 r10-12 c41-43`. `await act(["4"])` prints `#0 A4(right): obj 4 R 3x3 moved right 3 -> r10-12 c23-25`. In the same cell: `step()` shifts obj 4 by 3 columns per right move, BFS finds 6 more, `await act(["4"] * 6)` wins the level.
